# JFELi-et-al.-2025-
结合 JFS 的 Li et al., 2025，构建全量因子和精选因子：从 CSMAR 数据库中的 20 个核心会计变量出发，通过 5 种转换方法生成初始信号，保留 100 个完整全量因子；基于特征重要性评估框架，训练随机森林模型计算特征重要性得分，选取重要性排名前 30 的信号作为核心预测因子。之后应用 LightGBM 模型分别对筛选出的全量因子和精选因子预测收益分组对比各组的原始收益表现，与递归策略相比，检验中国市场上特征工程的作用。 针对论文实证步骤，编写 Python 代码，绘制全量信号、精选信号 LightGBM 策略表格，利用 CAPM、Fama3因子、Fama5 因子模型进行风险调整后的α表格和热力图，不同因子 LightGBM 策略绩效比较柱状图等。
